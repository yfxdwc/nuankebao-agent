# 暖客宝 用户手册 (大健康销售版)

> 给销售用, 简单直接
> 配套: `tools/SOP.md` (运维) + `docs/deploy.md` (部署)

## 📱 登录

1. 打开 暖客宝 app
2. 输入**手机号**
3. 点击**发送验证码**
4. 输入 6 位验证码 (开发期: `123456`)
5. 登录成功

## 👤 客户管理

### 新增客户

1. 主页 → **+ 新增客户** (或 客户 tab → 右下角 +)
2. 填写:
   - **姓名** (必填)
   - **手机号** (必填, 11 位)
   - **性别** / **出生年** (可选)
   - **健康标签** (多选: 肩颈 / 睡眠差 / 体寒 等)
   - **既往病史** (过敏 / 慢性病 等)
   - **备注** (VIP / 朋友介绍 等)
3. 点**保存**

### 查看 / 编辑客户

1. 客户 tab → 点击某客户
2. 详情页查看:
   - 基本信息 + 健康标签
   - **养生记录** (点击看详情)
   - **联系记录**
3. 右上角 ✏️ 编辑

### 搜索客户

- 客户 tab 顶部搜索框
- 输入**姓名** 或**手机号**
- 实时筛选

## 💆 养生记录 (核心功能)

### 新增养生记录

1. 主页 → **+ 新增养生记录** (或 养生 tab → 右下角 +)
2. 填写:
   - **客户 ID** (必填, 数字)
   - **服务日期** (默认今天)
   - **服务项目** (下拉选择: 肩颈经络 / 艾灸 / 拔罐 等)
   - **身体部位** (多选 chip: 肩颈 / 腰部 / 膝盖 等)
   - **理疗前/后 状态** (疼痛度 0-10 + 睡眠质量 0-10)
   - **使用耗材** (动态添加: 精油 5ml / 热敷包 1 个)
   - **理疗过程** (自由文本)
   - **客户反馈** (客户主诉)
   - **下次建议日期** (复购建议)
3. **📷 拍照** (理疗前后对比图)
   - 点 + 按钮 → 选**拍照** / **从相册**
   - 最多 9 张
   - 长按或点 X 删除
4. 点**保存**

### 录入小技巧

- **疼痛度** 0=无痛, 10=剧痛; **睡眠质量** 0=很差, 10=很好
- **部位多选** + **状态对比** = AI 复购预测的核心数据
- **照片** 上传后, 客户详情会显示缩略图

## 🔔 跟进任务

### 创建跟进任务

1. 跟进 tab → 右下角 +
2. 选**客户** + 写**原因** + 选**到期时间**
3. 选填 **AI 建议** (从 AI 助手复制)
4. 创建

### 完成 / 取消任务

- 跟进 tab → 某任务右侧 ⋮ → **✓ 完成** 或 **✗ 取消**

### 分组 (按到期时间)

- ⚠️ **已逾期** (红色, 优先处理)
- 📅 **今天**
- 📆 **本周**
- 🗓️ **更晚**

## 🤖 AI 助手

### 客户画像

1. AI tab → 选客户
2. 点**生成画像**
3. AI 返回:
   - 健康档案
   - 服务偏好
   - 跟进建议
4. 可复制 / 重新生成

### 跟进话术

1. AI tab → 选客户
2. 切到**跟进话术** tab
3. 点**生成**
4. AI 返回话术 (开场 + 推荐 + 预约)
5. 一键**复制话术** → 微信发给客户

> 💡 如果**未配 MINIMAX_API_KEY**, AI 走 mock 模式 (固定模板, 但能用)

## 📊 报表

- 报表中心: 月度到店趋势 + 项目分布 + 复购周期
- 仪表盘: 4 个实时统计卡

## 💡 实战流程示例

### 客户王女士到店,做完肩颈经络理疗

```
1. 打开 暖客宝 → 客户 tab → 搜 "王女士"
2. 进入详情 → 点 "+ 新增养生记录"
3. 选项目: 肩颈经络理疗
4. 部位: 勾选 肩颈
5. 理疗前疼痛度: 8 (问客户感觉)
6. (做完理疗, 再问客户感觉)
7. 理疗后疼痛度: 4
8. 拍 1-2 张对比图
9. 客户反馈: "肩膀轻多了"
10. 下次建议: 14 天后
11. 保存
```

### 5 天后,系统建议跟进王女士

```
1. 打开 暖客宝 → 跟进 tab
2. 看到 "王女士 - 复购提醒" (本周)
3. 点卡片 → 进入客户详情
4. 返回 AI tab → 选王女士 → "跟进话术" → 生成
5. 复制话术 → 微信发给王女士
6. 跟进 tab → 该任务 → ⋮ → ✓ 完成 + 备注
```

## ⚠️ 注意事项

- **手机号格式**: 必须 11 位, 1[3-9]xxxxxxxxx
- **健康标签**: 多选 chip, 直接点切换
- **照片**: 一次最多 9 张, 单张 < 5MB
- **AI 真实模式**: 需要在 .env 设 `MINIMAX_API_KEY`, 否则用 mock 模板
- **数据安全**: 客户手机号 / 健康数据在数据库中**加密存储**, 任何泄露都拿不到明文

## 🆘 常见问题

**Q: 忘记退出,会泄露数据吗?**
A: 暖客宝 有 session cookie 30 天过期, 设备丢失建议立即通知店长远程清除。

**Q: 录入时手抖填错了怎么办?**
A: 客户详情页 → 右上角 ✏️ 编辑修改; 养生记录也支持编辑。

**Q: 客户没收到验证码?**
A: 阿里云短信偶尔延迟, 1 分钟后重试; 或联系店长看是不是账户余额不足。

**Q: AI 话术看不懂,能调整吗?**
A: 可以! 话术是参考, 你根据客户性格微调后发送; 多次生成会得到不同结果。

**Q: 怎么把客户的照片发给客户自己?**
A: 当前版本不支持, 联系店长, W4 (后续) 会加"分享"功能。
