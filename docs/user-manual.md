# 暖客宝 用户手册 (大健康销售版)

> 给销售用, 简单直接
> 配套: `tools/SOP.md` (运维) + `docs/deploy.md` (部署)

## 📱 登录

1. 打开 暖客宝 app
2. 输入**手机号**
3. 点击**发送验证码**
4. 输入 6 位验证码 (开发期: `123456`)
5. 登录成功

## 👤 客户管理

### 新增客户

1. 主页 → **+ 新增客户** (或 客户 tab → 右下角 +)
2. 填写:
   - **姓名** (必填)
   - **手机号** (必填, 11 位)
   - **性别** / **出生年** (可选)
   - **健康标签** (多选: 肩颈 / 睡眠差 / 体寒 等)
   - **既往病史** (过敏 / 慢性病 等)
   - **备注** (VIP / 朋友介绍 等)
3. 点**保存**

### 查看 / 编辑客户

1. 客户 tab → 点击某客户
2. 详情页查看:
   - 基本信息 + 健康标签
   - **养生记录** (点击看详情)
   - **联系记录**
3. 右上角 ✏️ 编辑

### 搜索客户

- 客户 tab 顶部搜索框
- 输入**姓名** 或**手机号**
- 实时筛选

## 💆 养生记录 (核心功能)

### 新增养生记录

1. 主页 → **+ 新增养生记录** (或 养生 tab → 右下角 +)
2. 填写:
   - **客户 ID** (必填, 数字)
   - **服务日期** (默认今天)
   - **服务项目** (下拉选择: 肩颈经络 / 艾灸 / 拔罐 等)
   - **身体部位** (多选 chip: 肩颈 / 腰部 / 膝盖 等)
   - **理疗前/后 状态** (疼痛度 0-10 + 睡眠质量 0-10)
   - **使用耗材** (动态添加: 精油 5ml / 热敷包 1 个)
   - **理疗过程** (自由文本)
   - **客户反馈** (客户主诉)
   - **下次建议日期** (复购建议)
3. **📷 拍照** (理疗前后对比图)
   - 点 + 按钮 → 选**拍照** / **从相册**
   - 最多 9 张
   - 长按或点 X 删除
4. 点**保存**

### 录入小技巧

- **疼痛度** 0=无痛, 10=剧痛; **睡眠质量** 0=很差, 10=很好
- **部位多选** + **状态对比** = AI 复购预测的核心数据
- **照片** 上传后, 客户详情会显示缩略图

## 🔔 跟进任务

### 创建跟进任务

1. 跟进 tab → 右下角 +
2. 选**客户** + 写**原因** + 选**到期时间**
3. 选填 **AI 建议** (从 AI 助手复制)
4. 创建

### 完成 / 取消任务

- 跟进 tab → 某任务右侧 ⋮ → **✓ 完成** 或 **✗ 取消**

### 分组 (按到期时间)

- ⚠️ **已逾期** (红色, 优先处理)
- 📅 **今天**
- 📆 **本周**
- 🗓️ **更晚**

## 🤖 AI 助手

### 客户画像

1. AI tab → 选客户
2. 点**生成画像**
3. AI 返回:
   - 健康档案
   - 服务偏好
   - 跟进建议
4. 可复制 / 重新生成

### 跟进话术

1. AI tab → 选客户
2. 切到**跟进话术** tab
3. 点**生成**
4. AI 返回话术 (开场 + 推荐 + 预约)
5. 一键**复制话术** → 微信发给客户

> 💡 如果**未配 MINIMAX_API_KEY**, AI 走 mock 模式 (固定模板, 但能用)

## 📊 报表

- 报表中心: 月度到店趋势 + 项目分布 + 复购周期
- 仪表盘: 4 个实时统计卡

## 💡 实战流程示例

### 客户王女士到店,做完肩颈经络理疗

```
1. 打开 暖客宝 → 客户 tab → 搜 "王女士"
2. 进入详情 → 点 "+ 新增养生记录"
3. 选项目: 肩颈经络理疗
4. 部位: 勾选 肩颈
5. 理疗前疼痛度: 8 (问客户感觉)
6. (做完理疗, 再问客户感觉)
7. 理疗后疼痛度: 4
8. 拍 1-2 张对比图
9. 客户反馈: "肩膀轻多了"
10. 下次建议: 14 天后
11. 保存
```

### 5 天后,系统建议跟进王女士

```
1. 打开 暖客宝 → 跟进 tab
2. 看到 "王女士 - 复购提醒" (本周)
3. 点卡片 → 进入客户详情
4. 返回 AI tab → 选王女士 → "跟进话术" → 生成
5. 复制话术 → 微信发给王女士
6. 跟进 tab → 该任务 → ⋮ → ✓ 完成 + 备注
```

## 👤 我的 (个人资料 + 设置)

底部导览最右边「我的」, 一页看全: 我是谁 / 我下面有谁 / 我干了多少 / 手机上的设置。

### 看 / 改我的资料

| 位置 | 内容 |
|---|---|
| 头像区 | **头像 (点一下可换: 拍/相册/挑现成的)** + 姓名 (加盟网络里认这个名) + 角色 (销售员/店长/管理员) + 门店 + 手机号 |
| 手机号 | 默认打码显示 (138****8000), 点 👁 看全号, 点 📋 复制 (发给客户前先复制) |
| 加盟身份 | 编号 / 位置 (A线-B线) / 层级 / 我的上级 (点一下可看上级详情) / 加入时间 / 我的下线人数 |
| 数据概览 | 客户 / 待办跟进 / 本月拜访 / 本月新增客户 + 累计互动 |
| 编辑资料 | 点「编辑我的资料」改 **姓名** 和 **备注** (手机号是登录账号, 换号找管理员) |

> 数据概览是**全部客户（整个账号能看到的）** 口径: 数字跟客户列表的条数对得上,
> 不是只算自己新建的客户。

### 开通会员 (内测: 微信扫码付款)

1. 「我的」→ 会员 → **开通会员**
2. 选一个: **1 个月 ¥69** / **3 个月 ¥189**
3. 用微信扫屏幕上的收款码付款 (收款码是管理员的, 页面上会写收款人名字, **核对后再付**)
4. 付款时**备注写手机号后 4 位** (方便管理员对账)
5. 回到 App 点「**我已支付**」(可选: 传一张付款截图)
6. 等管理员确认 (通常几分钟); 确认后「我的」页会显示 **会员中 · 有效期至 X 月 X 日**

> 会员功能共 9 项: AI 助手 · 跟进建议 · 客户画像 · 效果分析 · 跟进推荐 · 互动记录 ·
> 生日提醒 · 图片上传 · 沙龙发起。免费版其余功能都能用。

**自动续费说明**: ¥49/月 的连续包月价要等微信支付上线后才能开通; 内测期间按 ¥69/月 手动续费。

> **管理员账号 (= 系统后台账号) 是永久会员**, 不需要付费、不会到期, 「我的」页会显示
> 「管理员账号 · 永久会员」并且没有开通/续费入口。

### 管理员: 怎么开通会员 (核销)

1. 收到用户「我已支付」后, 「我的」→ **管理员工具** → 付款申请 (待审)
2. 对一下微信到账 (备注里的手机号后 4 位 + 金额); 有疑问就点开用户传的截图
3. 对上了点「**通过并开通**」→ 对方立刻 +30 天; 对不上点「驳回」(可写原因)
4. 第一次用先点「**上传/更换微信收款码**」, 把收款码图片传上去 (用户端就会显示)

> 只有 admin 角色看得到「管理员工具」; 每次核销都会留审计记录 (谁、何时、给谁开了多久)。

### 推荐码 (我有朋友想用我的码)

「我的」→ 会员 → **我的推荐码** (6 位), 把码发给朋友。

- **只在朋友"建号"时有效**: 邀请制下账号由管理员创建, 所以**把码给管理员, 让管理员建号时填**
- 填上后: 朋友立刻得 15 天会员, 你也得 15 天 (你的那 15 天在朋友成为加盟者后到账)
- 「我的」页**没有**填别人推荐码的入口 —— 想用别人的码, 同样告诉管理员, 建号时填

### 换个头像

「我的」→ 点头像 (或点下面的「换头像」) → 三种方式任选:

| 方式 | 说明 |
|---|---|
| 拍一张 | 现拍一张 (会压到 512×512, 不用怕太大) |
| 从相册选 | 挑一张现成照片 |
| 挑一个现成的 | 8 个花草茶禅图标 (绿叶 / 花朵 / 喝茶 / 静心 / 爱心 / 暖阳 / 养生 / 清泉), **不想露脸就选这些** |
| 恢复默认头像 | 回到"姓名第一个字" |

头像存在公司自己的服务器上, 换手机、重装 App 都还在, 不用重新设。

### 把字调大 / 调小

「我的」→ 显示与存储 → 选 **小 / 标准 / 大 / 特大**, 选完**立即生效**, 全 App 文字都变
(包括客户页、表单、弹窗)。觉得字太大一屏看不清几个人就选「**小**」, 看不清就选「大/特大」。
选择会记在这台手机上, 下次打开还是这个字号。

### 清理缓存

「我的」→ 显示与存储 → 清理图片缓存: 养生记录里的照片会临时存在手机上, 清掉只是下次再看要重新加载, **不影响任何数据**。

### 检查更新 / 装新版

「我的」→ 关于与帮助 → 检查更新: 能看到手机上的版本 vs 服务器上的版本, 服务器上有新包时
直接点「下载 / 更新安装包」(会跳到浏览器下载), 或者点「扫码安装」出二维码让同事扫着装。
装新版直接覆盖, 数据不会丢。

### 连不上怎么办

「我的」→ 关于与帮助 → 网络自检: 会当场测一次服务器, 告诉你通不通、多快。
连不上时点「复制诊断信息」, 把那段话粘给管理员, 不用自己描述故障。

### 用不明白 / 客户问数据安不安全

「我的」→ 关于与帮助: 里面有 6 条常用操作说明 + 数据安全说明
(数据存在公司自己的服务器、手机号和健康信息加密、谁能看、改动留痕、每天备份) —— 客户问起来直接念。

## ⚠️ 注意事项

- **手机号格式**: 必须 11 位, 1[3-9]xxxxxxxxx
- **健康标签**: 多选 chip, 直接点切换
- **照片**: 一次最多 9 张, 单张 < 5MB
- **AI 真实模式**: 需要在 .env 设 `MINIMAX_API_KEY`, 否则用 mock 模板
- **数据安全**: 客户手机号 / 健康数据在数据库中**加密存储**, 任何泄露都拿不到明文

## 🆘 常见问题

**Q: 忘记退出,会泄露数据吗?**
A: 暖客宝 有 session cookie 30 天过期, 设备丢失建议立即通知店长远程清除。

**Q: 录入时手抖填错了怎么办?**
A: 客户详情页 → 右上角 ✏️ 编辑修改; 养生记录也支持编辑。

**Q: 客户没收到验证码?**
A: 阿里云短信偶尔延迟, 1 分钟后重试; 或联系店长看是不是账户余额不足。

**Q: AI 话术看不懂,能调整吗?**
A: 可以! 话术是参考, 你根据客户性格微调后发送; 多次生成会得到不同结果。

**Q: 怎么把客户的照片发给客户自己?**
A: 当前版本不支持, 联系店长, W4 (后续) 会加"分享"功能。
