## TL;DR

把暖客宝从"screens/ 平铺 + 散落脚本"重构为**「双域 + 底座 + 模块化插件」**架构:

- **APK 域** = 主产品 (销售员用的移动端) → 物理模块化 (`flutter_app/lib/core/` + `modules/`)
- **WEB 域** = 开发项目 APK 用的脚手架 → 文档化视图 (`docs/dev-modules/`, 物理位置不动)
- **★ 客户/加盟关系** 抽 `RelationSystem` 接口 + `FranchiseRelationSystem` 默认实现 → 未来换「分销」「会员」「上下级」**零调用方改动**

## 4. ★ RelationSystem 接口契约 (Phase 6 重点)

**接口定义** ([flutter_app/lib/modules/relation/lib/relation_system.dart](../../flutter_app/lib/modules/relation/lib/relation_system.dart)):

```dart
abstract class RelationSystem {
  String get name;
  Future<List<RelationNode>> getGraph(String rootId);
  Future<RelationNode?> getNode(String nodeId);
  Future<List<RelationNode>> getChildren(String parentId);
  Future<void> addRelation({
    required String fromId,
    required String toId,
    required RelationType type,
  });
  Future<void> removeRelation({required String fromId, required String toId});
  Future<List<RelationPath>> findPaths({
    required String fromId,
    required String toId,
  });
}
```

**数据契约** ([relation_node.dart](../../flutter_app/lib/modules/relation/lib/relation_node.dart)):

```dart
enum RelationType { parent, child, peer, manager, referral }

class RelationNode {
  final String id;
  final String name;
  final String? avatarUrl;
  final Map<String, dynamic> metadata;
}

class RelationPath {
  final List<RelationNode> nodes;
  final List<RelationType> edges;
}
```

**默认实现** ([franchise_relation.dart](../../flutter_app/lib/modules/relation/lib/franchise_relation.dart)):

```dart
class FranchiseRelationSystem implements RelationSystem {
  final FranchiseeService _service;
  FranchiseRelationSystem(this._service);

  @override String get name => 'franchise';

  @override
  Future<List<RelationNode>> getGraph(String rootId) async {
    final tree = await _service.getMyTree(depth: 3);
    return _flattenTree(tree); // FranchiseeTreeNode → List<RelationNode>
  }
  // ... 其他 6 个方法类似
}
```

**★ 切换点** ([relation_system_provider.dart](../../flutter_app/lib/modules/relation/lib/relation_system_provider.dart)):

```dart
final relationSystemProvider = Provider<RelationSystem>((ref) {
  final svc = ref.watch(franchiseeServiceProvider);
  return FranchiseRelationSystem(svc); // ← 改这一行即可切换关系系统
});
```

**未来切换示例** (分销关系):

```dart
// 1. 新建 distribution_relation.dart: class DistributionRelationSystem implements RelationSystem { ... }
// 2. 改 relation_system_provider.dart: return DistributionRelationSystem(svc);
```
