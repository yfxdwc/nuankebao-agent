# 收款码目录 (内测人工收款通道)

App「我的 → 会员 → 开通会员」弹层里显示的收款码。

## 当前状态: ✅ 已接入

- 文件: `wechat-qr.png` (900×900, 4-bit 调色板, ~48KB)
- 来源: 主人 2026-09-19 提供的微信个人收款码截图 (1118×1524)
- 处理: OpenCV 自动定位二维码 → 裁切 + 10% 静默区 + 白底放大到 900×900 →
  16 色量化压体积; 处理前后都用 `cv2.QRCodeDetector()` 复扫, **payload 一致**(`wxp://…` 微信收款协议)
- 生效方式: 服务端 `GET /api/billing/pay-info` 没配置 `manual_wechat_qr_url` 时会用本文件
  (`qrAvailable=true`), 客户端不再显示"还没设置收款码"

## 换收款码 (两种方式, 任选)

1. **App 内上传 (推荐)**: 管理员账号 → 「我的 → 管理员工具 → 上传/更换微信收款码」
   → 存到 `/uploads/…`, 写进 `billing_config.manual_wechat_qr_url`, **优先于本目录静态文件**
2. **换静态文件**: 覆盖本目录的 `wechat-qr.png` 即可 (服务端会立刻用新的, 无需重启)

> ⚠️ 本目录的图片**不入 git** (见根目录 `.gitignore`): 个人收款码属于私人收款凭证,
> 一旦进历史就很难彻底撤下。生产机上放文件 或 用 App 内上传。
>
> 💡 上传收款码前建议先裁到二维码本身 (四周留白), 这样在手机上更大更好扫。
