# 收款码兜底目录

内测人工收款通道 (`docs/adr/0012-membership-billing.md` §7) 的**静态兜底**位置。

- 把收款码图片保存为 **`public/payment/wechat-qr.png`** → App「开通会员」弹层自动用它。
- 或者（推荐）在 App 里用管理员账号：**我的 → 管理员工具 → 设置收款码** 上传（存到 `/uploads/`，随时能换，不用改服务器文件）。
- 上传过的配置优先于本目录的静态文件（`billing_config.manual_wechat_qr_url`）。

> ⚠️ 收款码是**个人微信收款码**（内测临时方案）：不建议提交到 git（`git status` 里会看到图片文件）。
> 若确实要入库，请自行确认没有泄露风险（收款码只是收款，不含账户信息）。
